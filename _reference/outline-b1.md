# Band 1 — Outline aller Kapitel und der Enden

Schritt 1 jedes Kapitel-Blocks aus `../MASTER_PROMPT.md` § 7, für **alle** Kapitel vorgezogen.
Hier steht der Teilgraph, **bevor** Prosa entsteht: Szenen, Kanten, POV, Konvergenz, Nebenwege,
Sackgassen, Proben, Wortbudget. Beats aus `../_knowledgebase/51-gotm-scene-detail.md`.

Vorgezogen, weil die Enden zuerst entworfen gehören (`01-cyoa-best-practices.md` § 5) und weil
jede spätere Kapitel-Entscheidung sonst blind wäre.

## Legende

`Sp` Spine · `Br` Branch · `Si` Side/Nebenweg · `De` Sackgasse · `Ko` Konvergenz · `In` Interlude
Wortbudget je Szene in DE; EN läuft ±15 % mit. Eine Szene sind 2–8 Seiten.

### Enden — Bedingungen als Bedingungsstruktur

```ts
// Reihenfolge = Prüfreihenfolge. Das erste passende Ende gewinnt.
E4 Der Eid       { all: [{stat:'standing',gte:7}, {stat:'heart',gte:6}] }
E3 Münze im Meer { all: [{flag:'coin.thrown'}, {stat:'heart',gte:5}] }
E2 Preis         { all: [{not:{flag:'coin.thrown'}},
                         {any:[{stat:'fortune',gte:6}, {flag:'attention.hunted'}]}] }
E5 Asche         { all: [{not:{stat:'heart',gte:3}}, {stat:'klinge→blade',gte:7}] }
E1 Ausgestoßene  — sonst. Immer erreichbar, nie ein Trostpreis.
```

**Jedes Ende bekommt einen Epilog-Absatz je Beziehungs-Flag** (Whiskeyjack, Quick Ben, Fiddler,
Kalam, Mallet, Paran, Tattersail, Crokus, Apsalar). Neun mögliche Absätze, gezeigt werden die
zutreffenden — so ist jedes Ende persönlich, ohne dass es fünfmal geschrieben werden muss.

**Kein Band-2-Teaser.** Höchstens eine diskrete Schlusszeile, dass hier der erste Band endet.
Der Pannion-Seher aus 8.6 bleibt ein Name ohne Fortsetzung — genau wie im Roman.

## Was aus diesem Outline folgt

1. **Die Prolog-Haken zahlen sich ein:** `paran.met.bridgeburner` → 3.1a (Fiddlers Fidel),
   `recruit.spoke.sorry` → 7.5, `recruit.saw.hound` → 3.4a und 6.7, `paran.helped.woman` → 10.E3.
2. **Herz ist der teuerste Wert und der wichtigste.** Drei der fünf Enden hängen daran, und jeder
   Punkt kostet Zeit, Münzen oder eine Gelegenheit.
3. **Fügung ist eine Falle mit Ansage.** Sie hilft messbar und führt zu E2, wenn man sie nicht
   loslässt. Die Münze wegzuwerfen ist die einzige Möglichkeit, das rückgängig zu machen.
4. **Jedes Kapitel hat mindestens eine Sackgasse, deren Payoff später zählt** — nie Bestrafung,
   immer Wissen, das nach dem Sprung zurück nützt.
5. **Elf Interlude-Wertetafeln** werden gebraucht: paran-child ✅, lorn ✅, dazu paran, tattersail,
   crokus, kruppe, toc, rallick.
